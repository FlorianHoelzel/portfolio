# Project screenshot sources

Actual public-site captures made in Chrome at 1440 × 960. TransitRadar and sumof.best were captured October 13, 2026; Yoshi’s dark theme was captured October 14, 2026. These are static screenshots, not live embeds or recreated interfaces. Sources are recorded below.

- `transitradar-map.jpg`: [TransitRadar Berlin](https://berlin.transitradar.de/). The map uses Leaflet and map data credited by the original app to OpenStreetMap and CARTO. The capture records the interface at that time, not current transport information.
- `yoshi-dark.jpg`: [Yoshi Leaderboards](https://yoshi.sumof.best/), captured in the site’s actual dark theme. The browser-only prototype displays imported static records. Game branding appears as part of the actual interface.
- `sumofbest-history.jpg`: [Sum of Best](https://sumof.best/), scrolled to the public demo archive's PB progression. The runner and archive data are explicitly illustrative demo data.

- `monolith-overview.png`: MONOLITH main dashboard captured from the owner's local instance on October 14, 2026. At the owner's request, the two names in the upper-right presence panel were covered using the built-in image-editing tool; the exported image is 1536 × 1024. The full overview retains device controls, presence states, arrival times, and the activity feed. No device controls were changed to stage the capture. The unredacted temporary capture was removed. The private instance is not linked as a public demo.

Technical descriptions were checked against each project's public README and package or source files. To update a screenshot, capture the real project, keep its meaningful attribution, inspect the result, and replace the asset and provenance together. Captions are retained as metadata; screenshot dialogs have no header bar, and the separator below each screenshot is removed; the owner requested that subtitles beneath all project screenshots be removed.
