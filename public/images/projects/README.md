# Project screenshot sources

Actual public-site captures made in Chrome at 1440 × 960. TransitRadar and sumof.best were captured October 13, 2026; Yoshi’s dark theme was captured October 14, 2026. These are static screenshots, not live embeds or recreated interfaces. Sources are recorded below.

- `transitradar-map.jpg`: [TransitRadar Berlin](https://berlin.transitradar.de/). The map uses Leaflet and map data credited by the original app to OpenStreetMap and CARTO. The capture records the interface at that time, not current transport information.
- `yoshi-dark.jpg`: [Yoshi Leaderboards](https://yoshi.sumof.best/), captured in the site’s actual dark theme. The browser-only prototype displays imported static records. Game branding appears as part of the actual interface.
- `sumofbest-history.jpg`: [Sum of Best](https://sumof.best/), scrolled to the public demo archive's PB progression. The runner and archive data are explicitly illustrative demo data.

MONOLITH's showcase contains no screenshot: it presents a labeled service-topology diagram based on the public repository architecture.

Technical descriptions were checked against each project's public README and package or source files. To update a screenshot, capture the real project, keep its meaningful attribution, inspect the result, and replace the asset and caption together.
